Introduction

Welcome to the official documentation page for Hexo's Abyssal Depths (HAD)! This portal covers everything you need to build, configure, and submit towers or mechanics for the project.

Installation Instructions

The HAD Building Kit is distributed via Roblox Studio places and standalone model assets:

  • Opening the uncopylocked template place on Roblox (recommended)
  • Downloading the .rbxl file from our GitHub releases page

Update Instructions

If you are using an older version of the kit, update to the latest framework by checking our GitHub releases page for update patches and migration logs.

Website Navigation

Use the top navigation bar to jump between documentation, API reference, and update logs. The left sidebar handles category navigation within each section.

Documentation

Detailed documentation for each Client Object and kit module can be found under the Client Objects category.

Global Configuration Documentation

Custom settings for ambient lighting, physics modifiers, gravity fields, and UI triggers can be edited inside the Global Settings folder inside ServerStorage.
